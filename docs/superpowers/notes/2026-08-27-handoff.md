## Tooling gotchas (hard-won)

- Headless CDP `page.mouse.click` does NOT emit PointerEvents — drive 3D clicks with synthetic `PointerEvent` dispatch on the canvas (helper pattern in session history).
- Overlay close button: exact `title === 'Close'`. Loose `/close/i` matches hidden "Close this PDF" gallery buttons → can delete PDFs / hang on confirms. Always `dialogs:"dismiss"`.
- Fiber walking: three objects live in `useRef` hooks — read hook-node `.memoizedState.current` (Map of condition Groups) from any DOM node's `__reactFiber`. Camera/renderer are effect-local consts (unreachable); label chip = absolutely-positioned divs inside mountRef.
- Click-grid hit maps vary with camera tilt; RESET VIEW ≠ top-down. To find a shape on screen, sweep cells and read `selectedId` from the fiber.
- `sq(center, half)` in scene3d tests = CENTER + HALF-EXTENT (a corner-semantics fixture "passed" two tests by luck — rev-3 catch).
- `darkMode` (sheet negative print, `opentakeoff_dark`) ≠ chrome theme (`opentakeoff_theme`) — isDark/grid/labels read the chrome theme.
- Fixture: `web/test/fixtures/3d-view-test.otk` (regen: `node test/fixtures/make-3d-test-project.mjs`); covers every 3D case incl. RC-1 roll rooms.
