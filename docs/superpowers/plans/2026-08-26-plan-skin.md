## Task 2 — TakeoffCanvas: one-shot raster + prop

- TakeoffCanvas state: `const [planSkin, setPlanSkin] = useState(null); // { canvas, sheetKey }`
  and `const planSkinSeqRef = useRef(0);`
- Effect keyed `[show3d, active3dKey]`: synchronously
  `setPlanSkin(null)`; if `!show3d` return; `seq = ++planSkinSeqRef.current`;
  read `pageObjsRef.current.get(active3dKey)`, `renderScalesRef` rs,
  `focusPanel.img.w/h`; `factor = Math.min(1, PLAN_SKIN_MAX_DIM/w,

  `Math.round(h*factor)`; `pageObj.render({ canvasContext, viewport:
  pageObj.getViewport({ scale: rs*factor }), background: "#ffffff" }).promise`;
  after await, `if (seq !== planSkinSeqRef.current) return;`
  `setPlanSkin({ canvas, sheetKey: active3dKey })`. Guard `!pageObj || !img.w`.

## Task 3 — View3D: the plane + panel controls

- Module consts beside `MAX_EXPLODE_FT`:
  `PLAN_SKIN_OPACITY = 0.4`, `PLAN_SKIN_DROPOPEN_FT = 0.05`,
  `PLAN_SKIN_RENDER_ORDER = -1`,
  `PLAN_SKIN_TINT = new THREE.Color(SVG.cobalt).lerp(new THREE.Color("#ffffff"), 0.6)`
  (import SVG from ../lib/ui.js).
- Props: `planSkin` ({canvas, sheetKey} | null). State: `planOn` (true),
  `planTint` (false), `planOpacity` (PLAN_SKIN_OPACITY). Not persisted.
- Dedicated effect keyed `[planSkin, sheet.widthPx, sheet.heightPx, sheet.upp]`:
  if existing plane → `scene.remove` + `disposeObject3D` FIRST; if
  `!planSkin` return. Build: `planPlane(sheet)` → geo
  `new THREE.PlaneGeometry(wFt, hFt).rotateX(-Math.PI/2)`; texture
  `new THREE.CanvasTexture(planSkin.canvas)` with `flipY = false`,
  `colorSpace = THREE.SRGBColorSpace`, `anisotropy = Math.min(8,
  renderer.capabilities.getMaxAnisotropy())`; material
  `MeshBasicMaterial({ map, transparent: true, opacity: planOpacity,
  depthWrite: false, side: THREE.FrontSide })` — NO clippingPlanes; mesh
  `position.set(cx, -PLAN_SKIN_DROPOPEN_FT, cw)`, `renderOrder =
  PLAN_SKIN_RENDER_ORDER`, `userData.excludeFromFit = true`, `visible =
  planOn`; `scene.add`. Keep `planeRef`.
- `computeVisibleBox`: skip `obj.userData.excludeFromFit` alongside the
  `!obj.visible` guard.
- Control effects (no rebuild): `visible = planOn`; `material.color =
  planTint ? PLAN_SKIN_TINT : white`; `material.opacity = planOpacity`
  (guard ref null).
- Panel: new `S.panelSection` block "Plan" above Explode: checkbox Plan,
  checkbox Tint (disabled when plan off), range 0–1 step 0.05 opacity
  (disabled when plan off) + `S.monoReadout` `{(planOpacity*100)|0}%`.
