# One-Click benchmark corpus

The scored fixture set the upstream RFC ([Kentucky-ai/opentakeoff#60](https://github.com/Kentucky-ai/opentakeoff/issues/60), item E) requires: golden room polygons scored by IoU, with the four required metrics and a non-zero exit when a gate fails.

```bash
cd web && npm run bench     # also runs inside `npm run check` and CI (.github/workflows/ci.yml)
```

## What it scores

Every probe is a seed click scored through the **production pipeline** (trace + snap, the ring the app actually returns — audit A5b), then compared to a golden polygon or an expected refusal.

| bucket | n | what the golden is | proves |
|---|---|---|---|
| synthetic | 9 | truth-by-construction: linework and golden come from the same numbers (`corpus.ts`) | **accuracy**, engine-independent |
| engine-pinned | 12 | the engine's own reviewed traces on the two real plans (`corpus/*.json`) | **regression safety only — not accuracy** |
| refusal | 3 | expected refusal (open space, oversized, doorway interior) | honest refusal |
| known-fail | 4 | tracked limits, excluded from metrics but xpass-monitored | honesty |

Metrics emitted: **mean/floor IoU, refusal rate, leak rate, per-probe deltas**, plus cross-resolution agreement (ws ×1/0.75/0.5, RFC failure mode #3) and a mask-fidelity (un-snapped) reading reported but ungated.

## Plan sources

Both committed under `demo/`; the bench re-extracts linework live via pdf.js, so the corpus is reproducible from the PDFs.

- `sample-plan.pdf` — fully synthetic, generated by `demo/make_sample_plan.py`. No copyright.
- `sample-finish-plan.pdf` — a publicly-released U.S. VA federal solicitation set. Document metadata stripped (verified: no `/Info`, `/Metadata`, `/Producer`, `/Author`). See `demo/README.md`.

## Gates (all exit 1)

Shape guard (fixture count drift), floor/mean IoU, refusal/leak/correct-refusal, cross-resolution verdict flips + pair-IoU floor, confidence gate (A2), pairwise tiling overlap, and known-fail **xpass detection** (a known-fail that starts passing fails the bench until re-pinned).

## Honest limits

- **No independent human-measured ground truth.** 12 of 21 goldens are the engine grading its own output, so the headline mean is 9 independent-accuracy cases + 12 regression cases. The human-measurement gates (`humanMaxSfErr`, `humanCoverageBand`, `from-takeoff.mts`) exist but no case feeds them. Closing this needs 2–3 hand-measured plans (remediation C1) — required to prove **item A** (face extraction), not required for the B/C/D/E slice.
- **No scanned-plan fixture.** The corpus is vector-plan only; the raster/scan path (RFC failure mode #6) is unit-tested, not corpus-covered.
- A drawing's own printed `NNN SF` callouts would be an independent cross-check (the plan measures itself). A callout harness is **not on this branch** (remediation item 0.10, still open); it lives on the round-9 research line and would need porting.
